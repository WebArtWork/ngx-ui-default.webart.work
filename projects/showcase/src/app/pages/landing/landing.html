Get the template

src/app is the actual product template — it ships with only a handful of starter pages. Everything else in the repository, including this showcase, the UI Kit and the Translator, exists only to support that template and isn't part of what you ship.

AI coding agents

We prefer working with this template through terminal-based AI coding agents — Claude Code, Codex CLI and Gemini CLI are the ones we use most, though most popular coding agents work the same way.

That's what the auto_awesome button in this showcase's own topbar is for: open it on any page, name your new page, pick a role and the elements you want to keep, then copy the generated prompt. From inside your cloned project, launch your agent (e.g. claude, codex, or gemini) and paste the prompt in — it builds that page for you inside src/app.

Then, in your new repo on GitHub, add an SSH_PRIVATE_KEY secret under Settings → Secrets and variables → Actions — the included .github/workflows/deploy.yml needs it to push your build to the gh-pages branch. Once it's run once, go to Settings → Pages and set the publishing source to the gh-pages branch.
