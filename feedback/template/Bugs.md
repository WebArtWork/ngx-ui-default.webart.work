# Bugs

This file is for anything that looked broken, didn't work, or didn't behave the way you expected while using the software.

You don't need to know *why* it happened or *how* to fix it — just describe what you saw. No severity, no priority, no IDs, no browser/device details, no formal steps to reproduce. If you happen to know something extra that might be useful, feel free to mention it naturally, but it's not required.

To add a screenshot, drop the image file into your `attachments/` folder and embed it like this:

```
![[attachments/sample.png]]
```

## Example (remove this once you've added your own bugs)

### The save button didn't seem to do anything

**What happened:** I filled out the form and clicked "Save", but nothing happened — no message, no confirmation, and when I refreshed the page my changes were gone.

**What I expected:** I expected either a confirmation that my changes were saved, or an error message telling me something went wrong.
